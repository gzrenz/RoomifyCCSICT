# Roomify: Classroom Reservation App for CCSICT Department

## Built with
- C# w/ Windows Forms
- Entity Framework Core 8 + SQLite

## Download the ZIP file to check the code and run the app (for groupmates)

1. Look for the green **`<> Code`** button near the top right.
2. Click it, then click **Download ZIP** 
3. Find the downloaded file **right-click** it.
4. Extract the file
   - ⚠️ Do **not** run the app from inside the ZIP file. It must be extracted first.
5. Open the extracted folder and find the solution file: **`ClassroomReservationOOP.sln`**
6. **Double-click it.** Visual Studio should open with the project loaded.
7. Run the app (f5 or the green triangle arrow thingy)
8. Voila, you are done
